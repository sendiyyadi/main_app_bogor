# Main App 🏔️

Main Aplikasi berbasis web untuk kebutuhan sistem informasi dan manajemen PBB. 

## 🚀 Teknologi yang Digunakan
*   **Backend:** PHP (CodeIgniter)
*   **Database:** PostgreSQL / MySQL *(hapus salah satu yang gak kepake)*
*   **Frontend:** HTML, CSS, JavaScript (termasuk Leaflet.js untuk peta)
*   **Environment:** Berjalan optimal di Windows Server, macOS atau Linux

## ⚙️ Persyaratan Sistem
*   PHP versi 7.0.33
*   Web Server (IIS Web Server) dengan dukungan *URL Rewrite* 

## 🛠️ Berisi Total 7 Module (4 Modul Aktif)
*  Admin
*  E-adm
*  Pos PBB
*  Pos PST
*  PBBM
*  Penagihan
*  Tool PBB
